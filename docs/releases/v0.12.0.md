# Deep Agent V3 v0.12.0

Release date: 2026-07-26

## Outcome

v0.12.0 implements the safe, testable current-version items from the four V3
planning and code-review documents while preserving the architecture:

```text
CLI -> Runtime -> AgentState -> Prompt -> Capability -> Permission
ToolRequest -> PermissionManager -> ToolResult
```

DeepSeek remains the only inference provider. This release does not add a
parallel sub-Agent runtime, fallback provider, automatic A/B routing, or an
unattended strategy tuner.

## Changes

- Fail before project, Memory, or Vector setup when the private DeepSeek API key
  is missing. Vector is disabled by default and lazy when explicitly enabled.
- Return CLI exit `0` for completed Sessions, `2` for resumable incomplete
  Sessions, and `1` for setup/runtime errors.
- Reserve and checkpoint each model request before network I/O; enforce bounded
  per-turn model-request, token, and elapsed-time budgets across all phases.
- Make protocol-correction and abnormal-finish recovery counts configurable
  without duplicating `DeepSeekClient` HTTP retry/backoff.
- Upgrade AgentState to schema 7 and the core contract to version 3. Plan steps
  carry semantic type, parent, tool-round estimate, artifact IDs, validation
  rules, and progress weight. Terminal pre-claims and graph cycles are rejected.
- Show conservative progress based only on persisted satisfied steps.
- Validate JSON, YAML, Python, and DOCX artifacts. Managed `document.parse`
  emits a content-free receipt; Runtime trusts it instead of reading files.
  DOCX checks ZIP/OPC/XML/CRC, compression bounds, and non-empty text.
- Replay file apply/delete/undo lineage; deleted or undone artifacts no longer
  appear verified in completion gates or Session summaries.
- Enforce strict Memory kinds for new writes while reading legacy kinds; add
  dry-run capacity maintenance, protected durable kinds, and idempotent explicit
  confidence feedback.
- Record bounded scalar-only terminal performance history by `run_id`. It is an
  observer only and cannot change Runtime strategy or user configuration.
- Add portable POSIX/Windows locks, safe `shlex.join()` shell arguments,
  injectable capability health, and aligned optional dependency minimums.

## Verification

The release worktree collected and passed 502 tests. Ruff check, Ruff format
check for program/test/script sources, `compileall`, `pip check`, and
`git diff --check` passed. The suite includes real PTY interaction and focused
platform lock, shell quoting, Key/Vector startup, budget, progress, artifact,
Memory, performance-history, Runtime, Session, and Resume regressions.

No online DeepSeek request was repeated for this release, avoiding unnecessary
private API cost while retaining deterministic offline verification.

## Compatibility and rollback

Configuration migration only adds missing defaults. An old Word
`document.parse` record without the v0.12.0 managed receipt fails closed; Resume
and parse that artifact once again. v0.11.0 cannot load a schema 7 Session, so
finish active v0.12.0 Sessions before rollback:

```bash
git switch --detach v0.11.0
.venv/bin/pip install -e .
```

Do not delete private Memory, Session, Vector, logs, or `.project-agent` data.

## Reference boundary

Behavioral comparison used
`https://gitee.com/free/claude-code/tree/claude/` at commit
`b17913e26fd4278ad5cd4b32ed3bde86bf1444e9`. Its README describes a leaked
proprietary snapshot and provides no reusable license, so no source was copied.
Only independently tested boundaries such as runtime-owned task state, bounded
session output, completion evidence, result pairing, and finite recovery
informed this implementation.

Deferred items include a Durable Intent Journal, partial artifact commits,
verified parallel sub-Agents, automatic A/B experiments/route tuning, Memory
import/export, and non-DeepSeek providers.
