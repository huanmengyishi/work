# Deep Agent V3 v0.12.1

Release date: 2026-07-26

## Outcome

v0.12.1 is a release-engineering patch. It does not change Runtime behavior,
AgentState schema 7, core contract 3, configuration migration, or the
DeepSeek-only provider boundary.

The v0.12.0 GitHub Actions run installed Ruff 0.16.0 from the open-ended
`ruff>=0.6.0` development dependency. Ruff 0.16.0 expanded its default lint
selection, so all three Python jobs stopped at 210 newly enabled historical
policy findings before pytest or compileall ran. This was toolchain drift, not
a failure of the 502-test offline runtime verification.

## Changes

- Pin the release lint toolchain to the locally verified Ruff 0.15.21.
- Declare the existing `E4`, `E7`, `E9`, and `F` lint contract explicitly.
- Require the matching Ruff version in project configuration and print it in
  GitHub Actions before checks.
- Add a regression test for the release pin and lint selection.
- Synchronize package, CLI, Markdown, Word, and release metadata to 0.12.1.

The fixed `free/claude-code` snapshot has no Python, Ruff, or CI workflow to
copy. Its checked-in `bun.lock` nevertheless confirms the relevant release
principle: automation should consume a reproducible tool version instead of an
unbounded latest version. No source was copied from that unlicensed snapshot.

## Verification

The v0.12.0 runtime baseline remains 502 offline tests passed, plus isolated
version/help/init/missing-key/launcher smoke checks. v0.12.1 adds one focused
configuration regression. GitHub Actions runs Ruff, the complete test suite,
and compileall on Python 3.11, 3.12, and 3.13. Online DeepSeek authentication
remains deferred until API balance is restored.

## Rollback

v0.12.1 has no state or configuration-schema migration. To return to the
runtime-identical prior release:

```bash
git switch --detach v0.12.0
.venv/bin/python -m pip install -e .
```

Do not delete private Memory, Session, Vector, logs, or `.project-agent` data.
