# Deep Agent V3 0.13.0

发布日期：2026-07-29

0.13.0 完成 V3 综合改进方案的工程闭环，保持 DeepSeek-only，以及
`ToolRequest -> PermissionManager -> ToolResult` 的中央执行边界。Vector、HTTP、
MCP、daemon、自适应调参和实验仍默认关闭；可选依赖能力按需初始化。配置迁移只补
缺省值，不覆盖用户显式选择。

## 重点改进

- 成功任务可在当前 turn 至少完成 5 次受管工具调用后，使用同一 DeepSeek
  client 发起至多一次无工具、受预算的 Memory 精炼逻辑请求；底层仍服从有界网络
  重试和 Key 轮转。`memory.smart_reflection` 在新安装或缺失配置时默认开启，已有
  显式 `false` 不会被迁移覆盖；微小任务、失败任务、预算不足和非法响应均安全跳过。
- Runtime、Convergence 和 Tool Manager 按执行阶段、上下文窗口、历史证据、
  完成门、恢复、Capability 声明和权限执行器拆分；核心接口契约升至 5。
- AgentState schema 升至 8：首次可保留 200 个真实工具 receipt；溢出后窗口为
  1 个裁剪标记加最多 199 个真实 receipt，状态、记录、字典和嵌套均有 UTF-8
  字节硬门。Session Resume 只加载最近 16 个完整模型轮次，被保留的完整 JSONL
  由最多 4 个、总计 128 MiB 的哈希校验冷世代管理。
- 新增零模型 History Snip、Memory TTL/LRU 温缓存、严格 Memory transfer、
  Global Knowledge 类型/项目隔离，以及工具按需初始化。
- Memory transfer 使用有界版本化 JSON 和事务导入；global 只允许
  Knowledge/Lesson/Decision，默认编辑和删除不会跨项目或修改 global 记录。
- 核心依赖只保留 PyYAML、regex 和 wcwidth；Browser、Vector、Semantic 与 Document
  依赖继续通过 extras 显式安装。
- 接通能力退避/熔断、策略化 Task Plan、可选 Adaptive Convergence、
  Strategy Adjuster 和默认关闭的确定性实验框架。
- Durable Intent Journal 使用有界哈希链与 projection bridge；
  ArtifactRegistry 记录受管产物生命周期和跨步骤血缘。
- GitHub 当前树只保留应用、测试/CI、当前发布说明和最新版精简用户文档；
  历史报告、旧版用户文档和详细开发数据仅保存在本地归档。

## 兼容与安全

- DeepSeek 仍是唯一推理 Provider，没有备用模型或自动跨 Provider 切换。
- 所有系统动作继续经过 Tool Manager 和 PermissionManager；Memory 精炼没有工具权限。
- schema 1 Session 仍可迁移；新 schema 的未知未来版本失败关闭。
- 0.12.2 不理解 schema 8 或外置 JSONL 的 Session envelope 2；回滚前应完成或保留
  0.13.0 Session，不要删除 `.project-agent` 数据。
- Vector、Browser、Document 等重型可选能力维持按需安装或默认关闭。
- 不读取、提交或复制真实 API Key、Memory、Session、日志、浏览器会话和项目私有数据。
