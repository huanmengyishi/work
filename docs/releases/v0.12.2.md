# Deep Agent V3 v0.12.2

Release date: 2026-07-27

## Outcome

v0.12.2 is a documentation-publication patch. It does not change Runtime
behavior, AgentState schema 7, core contract 3, configuration migration, or the
DeepSeek-only provider boundary.

The complete v0.12.1 guide and work log were already committed under
`user-docs/`, but two duplicate v0.10.0 Word files remained at repository root.
GitHub therefore presented the stale documents prominently even though remote
`main`, `v0.12.1`, and the `user-docs/` copies were correct.

## Changes

- Remove the duplicate v0.10.0 Word files from repository root; byte-identical
  archived copies remain under the old-document directories.
- Publish the current versioned guide and work log at repository root and under
  `user-docs/`.
- Add direct current-document links to the source README.
- Add a regression test requiring exactly the current two release Word files at
  repository root and matching files under `user-docs/`.
- Synchronize package, CLI, Markdown, Word, and release metadata to 0.12.2.

## Verification

The v0.12.1 runtime baseline passed 503 tests on Python 3.11, 3.12, and 3.13.
v0.12.2 adds one offline repository-layout regression. No DeepSeek API request
is required or permitted for this publication fix while the user balance is
exhausted.

## Rollback

v0.12.2 has no state migration. To return to the runtime-identical prior tag:

```bash
git switch --detach v0.12.1
.venv/bin/python -m pip install -e .
```

Do not delete private Memory, Session, Vector, logs, or `.project-agent` data.
